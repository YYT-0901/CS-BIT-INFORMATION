### 教师端接口设计

#### 创建规则集

- 接口地址: `POST /rules/addRules` 

- | 参数名  | 参数类型 | 说明                  | 是否必传(默认值) |
  | ------- | -------- | --------------------- | ---------------- |
  | majorId | String   | 哪个专业的规则        | √                |
  | name    | String   | 规则集名              | ×                |
  | count   | Number   | 共有几个规则          | ×                |
  | status  | Number   | 状态(1:正常 0:不正常) | ×(1)             |

- 请求示例

  ```
  {
  	"majorId": 1111111111,
  	"name": 计算机专业的规则集,
  	"count": 7,
  	"status": 1,
  }
  ```

- 返回实例

  ```
  {
    "code": 200,
    "msg": "规则集创建成功",
    "data": null
  }
  ```

#### 自定义审核规则接口

- **接口地址**：`POST /teacher/rules`
- **功能描述**：教师创建或修改审核规则，包括文件命名格式、必交材料清单、PDF签名校验等规则。
- **请求参数**：
  - `ruleName`（审核规则名称，字符串类型）
  - `fileNamingFormat`（文件命名格式规则，字符串类型，如“学号_姓名_论文题目”）
  - `requiredMaterials`（必交材料清单，数组类型，包含材料名称）
  - `pdfSignatureCheck`（PDF签名校验规则，布尔类型，`true`表示启用，`false`表示不启用）
  - 其他规则相关参数根据实际需求添加

- 请求示例

```json
{
  "ruleName": "2025届毕业论文审核规则",
  "fileNamingFormat": "学号_姓名_论文题目",
  "requiredMaterials": ["论文正文", "开题报告", "中期检查表", "查重报告"],
  "pdfSignatureCheck": true
}
```

- 返回实例

```json
{
  "code": 200,
  "message": "审核规则创建成功",
  "data": {
    "ruleId": "rule123456",
    "ruleName": "2025届毕业论文审核规则"
  }
}
```



#### 批量审核学生材料接口

- **接口地址**：`POST /teacher/review/batch`

- **功能描述**：教师上传学生提交的材料文件，系统根据审核规则批量审核材料，自动生成问题报告。

- **请求参数**：

  - `ruleId`（审核规则 ID，字符串类型，关联自定义审核规则接口）
  - `materials`（学生提交的材料文件，数组类型，每个元素包含文件名和文件内容的 Base64 编码）

- **请求示例**：

  ```json
  {
    "ruleId": "rule123456",
    "materials": [
      {
        "fileName": "2022010101_张三_毕业论文.docx",
        "fileContent": "base64编码的文件内容"
      },
      {
        "fileName": "2022010101_张三_开题报告.pdf",
        "fileContent": "base64编码的文件内容"
      }
    ]
  }
  ```

  

- **返回示例**：

  ```json
  {
    "code": 200,
    "message": "批量审核完成",
    "data": {
      "reviewReports": [
        {
          "studentId": "2022010101",
          "studentName": "张三",
          "reviewResult": "部分合规",
          "problems": [
            {
              "materialName": "毕业论文",
              "problemDescription": "文件名不符合命名格式"
            },
            {
              "materialName": "开题报告",
              "problemDescription": "PDF签名缺失"
            }
          ]
        }
      ]
    }
  }
  ```

### 其他通用接口

#### 文件上传接口

- **接口地址**：`POST /file/upload`

- **功能描述**：用于上传文件，返回文件存储路径或文件 ID，供其他接口调用。

- **请求参数**：

  - `file`（上传的文件，包含文件名和文件内容的 Base64 编码）

- **请求示例**：

  ```json
  {
    "file": {
      "fileName": "example.docx",
      "fileContent": "base64编码的文件内容"
    }
  }
  ```

  

- **返回示例**：

  ```json
  {
    "code": 200,
    "message": "文件上传成功",
    "data": {
      "fileId": "file123456",
      "filePath": "/uploads/example.docx"
    }
  }
   
  ```

#### 文件下载接口

- **接口地址**：`GET /file/download`

- **功能描述**：根据文件 ID 或文件路径下载文件。

- **请求参数**：

  - `fileId`（文件 ID，字符串类型，可选参数）
  - `filePath`（文件路径，字符串类型，可选参数）

- **请求示例**：

  ```
  GET /file/download?fileId=file123456
  ```

  或

  ```
  GET /file/download?filePath=/uploads/example.docx
  ```

  

- **返回示例**：

  - 如果请求成功，直接返回文件内容，可通过 HTTP 响应头的 `Content-Disposition` 指定文件名，例如：

    ```
    Content-Disposition: attachment; filename="example.docx"
    ```

    然后返回文件的二进制内容。

  - 如果请求失败，返回错误信息，例如：

    ```json
    {
        "code": 404,
        "message": "文件不存在"
    }
    ```

    

### 安全与认证接口

#### 用户登录接口

- **接口地址**：`POST /auth/login`

- **功能描述**：用户登录，验证用户名和密码，返回认证令牌（Token）。

- **请求参数**：

  - `username`（用户名，字符串类型）
  - `password`（密码，字符串类型）

- **请求示例**：

  ```json
  {
    "username": "teacher123",
    "password": "password123"
  }
  ```

  

- **返回示例**：

  ```json
  {
    "code": 200,
    "message": "登录成功",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    }
  }
  ```

  

#### 用户注册接口

- **接口地址**：`POST /auth/register`

- **功能描述**：用户注册，创建新用户账户。

- **请求参数**：

  - `username`（用户名，字符串类型）
  - `password`（密码，字符串类型）
  - `role`（用户角色，字符串类型，如“teacher”或“student”）
  - `email`（用户邮箱，字符串类型，可选参数）

- **请求示例**：

  ```json
  {
    "username": "newteacher",
    "password": "newpassword",
    "role": "teacher",
    "email": "newteacher@example.com"
  }
  ```

  

- **返回示例**：

  ```json
  {
    "code": 200,
    "message": "注册成功"
  }
  ```

  

#### 用户信息获取接口

- **接口地址**：`GET /auth/userinfo`

- **功能描述**：通过 Token 获取当前登录用户的信息。

- **请求参数**：

  - `token`（认证令牌，字符串类型，通过 HTTP 请求头的 `Authorization` 字段传递）

- **请求示例**：

  

  Copy

  ```
  GET /auth/userinfo
  Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
  ```

  

- **返回示例**：

  ```json
  {
    "code": 200,
    "message": "获取用户信息成功",
    "data": {
      "username": "teacher123",
      "role": "teacher",
      "email": "teacher123@example.com"
    }
  }
  ```

### 错误处理

- **通用错误码**：

  - `400`：请求参数错误
  - `401`：未授权，Token 无效或缺失
  - `403`：禁止访问，用户权限不足
  - `404`：资源未找到，如文件或用户不存在
  - `500`：服务器内部错误

- **错误返回示例**：

  ```json
  {
    "code": 400,
    "message": "请求参数错误",
    "errors": [
      {
        "field": "ruleId",
        "message": "审核规则 ID 不能为空"
      }
    ]
  }
  ```
